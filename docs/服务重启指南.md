# FlintLoom 服务重启指南

本文说明如何在本地开发时**停止、重启** FlintLoom 相关服务，以及遇到端口占用、插件加载失败时的处理方法。

所有命令均在 **FlintLoom 项目根目录**（含 `package.json` 的目录）执行。

---

## 1. 服务与端口

| 端口 | 服务 | 启动方式 |
|------|------|----------|
| **5173** | Vite 开发服（React 工作台） | `pnpm desktop` / `pnpm desktop:app` |
| **7331** | FlintLoom Host（REST + SSE API） | 随 `desktop` 自动启动 |
| **7340** | 微信桥接（wechat-bridge） | `pnpm wechat-bridge` |

---

## 2. 推荐：一键重启命令

遇到「端口已被占用」或需要干净重启时，**优先使用以下命令**（会先结束占端口的旧进程，再重新启动）：

```powershell
# 浏览器模式（Host + Vite）
pnpm desktop:restart

# Electron 桌面版（Host + Vite + 原生窗口，可选系统文件夹）
pnpm desktop:app:restart

# 微信桥接
pnpm wechat-bridge:restart
```

启动成功后，终端会打印类似：

```
[restart] stopped PIDs: 17280
[restart] starting desktop…
[desktop] workspace: G:\AgentCode\PerAgent\FlintLoom
  ➜  Local:   http://127.0.0.1:5173/
```

浏览器访问：**http://127.0.0.1:5173/**

---

## 3. 仅停止服务（不重启）

```powershell
# 停止 desktop 相关（5173 + 7331 及 FlintLoom Electron / flintloom-electron）
pnpm desktop:stop
# 或
pnpm desktop:app:stop

# 停止微信桥接（7340）
pnpm wechat-bridge:stop

# 停止全部（5173 + 7331 + 7340 及 FlintLoom Electron / flintloom-electron）
pnpm services:stop
```

---

## 4. 首次启动（非重启）

若当前没有服务在跑，可直接启动：

```powershell
pnpm desktop          # 浏览器模式
pnpm desktop:app      # Electron 桌面版
pnpm wechat-bridge    # 微信桥接（需 Host 已在 7331 运行）
```

### 4.1 `desktop` 与 `desktop:app` 的区别

| 命令 | 说明 |
|------|------|
| `pnpm desktop` | 只起 Host + Vite，用**浏览器**打开 5173 |
| `pnpm desktop:app` | 同上，并打开 **Electron 窗口**；支持系统原生「选择文件夹」 |

进托盘后窗口不在任务栏，但 Electron 仍在。要停干净请用 `pnpm desktop:app:stop` / `restart`，不要只点关闭。

### 4.2 复用已有服务

若 **`pnpm desktop` 已在运行**，再执行 `pnpm desktop:app` 会**复用**已有的 Host 与 Vite，只打开 Electron 窗口，不会重复占端口。

## 5. 指定工作区目录

重启时 Host 需要加载工作区内的 `flintloom.yml`。

### 5.1 自动选择（默认）

在**含有 `flintloom.yml` 的目录**下执行 `*:restart` 时，会自动把**当前目录**设为工作区。

例如在 FlintLoom 根目录执行：

```powershell
cd G:\AgentCode\PerAgent\FlintLoom
pnpm desktop:restart
```

会使用 `G:\AgentCode\PerAgent\FlintLoom` 作为工作区。

### 5.2 手动指定环境变量

```powershell
$env:FLINT_WORKSPACE_ROOT="G:\AgentCode\PerAgent\FlintLoom"
pnpm desktop:restart
```

### 5.3 在 UI 中切换

打开工作台后，点击侧栏 **「选择工作区」**，输入 Windows 绝对路径（如 `G:\AgentCode\PerAgent\FlintLoom`），目录内需包含 `flintloom.yml`。

持久化路径保存在：`%USERPROFILE%\.flintloom\workspace`

## 6. 常见问题

### 6.1 `Port 5173 is already in use`

**原因**：已有 `pnpm desktop` / `desktop:app` 在跑，或僵尸 node 进程占用了端口。

**处理**：

```powershell
pnpm desktop:restart
# 或
pnpm desktop:app:restart
```

### 6.2 `port 7331 in use` / `PortInUseError`

**原因**：7331 被其他程序占用，或旧 Host 进程未退出。

**处理**：

```powershell
pnpm desktop:restart
```

若仍失败，手动结束进程（PowerShell）：

```powershell
Get-NetTCPConnection -LocalPort 5173,7331 -ErrorAction SilentlyContinue |
  Select-Object -ExpandProperty OwningProcess -Unique |
  ForEach-Object { Stop-Process -Id $_ -Force -ErrorAction SilentlyContinue }
```

然后重新 `pnpm desktop:restart`。

### 6.3 `Error: @flintloom/infographic`（插件加载失败）

**原因**：当前工作区的 `flintloom.yml` 中插件 `name` 配置错误，**不是端口问题**。

infographic 插件应写为：

```yaml
- id: infographic
  name: "@flintloom/infographic/plugin"
```

❌ 错误写法：`name: "@flintloom/infographic"`（这是函数导出，不是插件入口）

**处理**：

1. 检查终端里 `[desktop] workspace: ...` 打印的是哪个目录
2. 打开该目录下的 `flintloom.yml`，修正插件名
3. 或切换到正确工作区后重启：

```powershell
$env:FLINT_WORKSPACE_ROOT="G:\AgentCode\PerAgent\FlintLoom"
pnpm desktop:restart
```

### 6.4 纯前端改动需要重启吗？

**不需要**。修改 `apps/desktop` 下 React/CSS 等前端代码时，Vite 会热更新（HMR），刷新浏览器即可。

需要重启的情况：修改了 Host、插件、`flintloom.yml`、`.env`，或遇到端口/进程异常。

## 7. 命令速查表

| 命令 | 作用 |
|------|------|
| `pnpm desktop` | 启动 Host + Vite（浏览器） |
| `pnpm desktop:restart` | 停旧进程 + 启动 Host + Vite |
| `pnpm desktop:stop` | 停止 5173 / 7331 及 FlintLoom Electron（`flintloom-electron`） |
| `pnpm desktop:app` | 启动 Host + Vite + Electron |
| `pnpm desktop:app:restart` | 停旧进程 + 启动 Electron 版 |
| `pnpm desktop:app:stop` | 停止 5173 / 7331 及 FlintLoom Electron（`flintloom-electron`） |
| `pnpm wechat-bridge` | 启动微信桥接 |
| `pnpm wechat-bridge:restart` | 停旧进程 + 启动微信桥接 |
| `pnpm wechat-bridge:stop` | 仅停止 7340 |
| `pnpm services:stop` | 停止全部（5173 / 7331 / 7340 及 FlintLoom Electron（`flintloom-electron`）） |

## 8. 典型开发流程示例

**浏览器开发：**

```powershell
cd G:\AgentCode\PerAgent\FlintLoom
pnpm desktop:restart
# 打开 http://127.0.0.1:5173/
```

**需要系统文件夹选择器（Electron）：**

```powershell
cd G:\AgentCode\PerAgent\FlintLoom
pnpm desktop:app:restart
```

**同时跑微信桥接：**

```powershell
# 终端 1
pnpm desktop:restart

# 终端 2
pnpm wechat-bridge:restart
```

**全部停掉：**

```powershell
pnpm services:stop
```
